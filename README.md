## 1 Лабораторная работа по АиСД

**Вариант:** 20 (Бинарное дерево поиска)

### Исходный код
* Файл с кодом: [laba1.c](laba1/laba1.c)

### Принцип работы и алгоритмы
1. **Структура узла**: Каждый узел содержит целочисленное значение (`data`) и два указателя на дочерние узлы (`left`, `right`).
2. **Добавление узла (`add_node`)**: Рекурсивный алгоритм. Если добавляемое значение меньше значения в узле, оно отправляется в левое поддерево; если больше — в правое. **Примечание**: Дубликаты значений помещаются в левую ветку.
3. **Удаление узла (`remove_node`)**: Стандартное BST-удаление. При удалении узла с двумя детьми он заменяется на минимальный элемент из его правого поддерева (преемник), после чего этот преемник удаляется.
4. **Проверка уровня листьев (`leafs_on_same_level` - вариант 11/20)**: Рекурсивный обход в глубину (DFS). При нахождении первого листа (узел без потомков) программа запоминает его уровень/глубину. Для всех последующих листьев глубина сверяется с сохраненной. Если обнаруживается разница, обход прекращается и возвращается результат о том, что листья находятся на разных уровнях.

### Как запускать
1. Откройте терминал в корневой папке репозитория.
2. Скомпилируйте и запустите программу:
   * **macOS / Linux:**
     ```bash
     gcc laba1/laba1.c -o laba1/laba1
     ./laba1/laba1
     ```
   * **Windows (CMD / PowerShell):**
     ```cmd
     gcc laba1\laba1.c -o laba1\laba1.exe
     laba1\laba1.exe
     ```

### Что будет выведено / Инструкция пользователя
Программа работает в интерактивном режиме через консольное меню:
1. **Вывести дерево** (отображает структуру дерева горизонтально с отступами, пропорциональными уровню вложенности).
2. **Добавить узел** (запрашивает целое число).
3. **Удалить узел** (запрашивает целое число).
4. **Подсчитать количество узлов**.
5. **Проверить, все ли листья на одном уровне**.
6. **Выход из программы** (с очисткой памяти дерева).

**Пример сессии:**

## 2 Лабораторная работа по АиСД

**Вариант:** 11 (Метод пузырька и таблица с целым ключом, где ключ и данные хранятся вместе)

### Исходный код
* Файл с кодом: [laba2.c](laba2/laba2.c)

### Принцип работы и алгоритмы
1. **Структура элемента таблицы (`TableItem`)**: Структура, объединяющая в себе целочисленный ключ (`key`) и данные (`data`).
2. **Сортировка пузырьком (`bubble_sort`)**: Итерируется по массиву элементов и меняет местами соседние элементы, если они стоят в неправильном порядке (`t[j].key > t[j+1].key`). Алгоритм содержит оптимизацию: если за проход не было совершено ни одной перестановки, сортировка досрочно завершается.
3. **Демонстрационный тест**:
   * Создается базовая упорядоченная таблица из 11 элементов.
   * **Случай 1 (Упорядочена)**: Таблица сортируется в исходном состоянии.
   * **Случай 2 (Обратный порядок)**: Таблица переворачивается задом наперед с помощью `reverse_table` и затем сортируется.
   * **Случай 3 (Не упорядочена)**: Таблица перемешивается случайным образом с помощью алгоритма Фишера-Йетса (`shuffle_table`) и затем сортируется.
   * Измеряется и выводится время сортировки каждого случая с помощью функции `clock()`.
4. **Двоичный поиск (`bin_search`)**: Производится по отсортированной таблице (случай 3 после сортировки). Алгоритм делит отрезок поиска пополам и сужает границы поиска в зависимости от сравнения искомого ключа с центральным элементом. Сложность: $O(\log n)$.

### Как запускать
1. Откройте терминал в корневой папке репозитория.
2. Скомпилируйте и запустите программу:
   * **macOS / Linux:**
     ```bash
     gcc laba2/laba2.c -o laba2/laba2
     ./laba2/laba2
     ```
   * **Windows (CMD / PowerShell):**
     ```cmd
     gcc laba2\laba2.c -o laba2\laba2.exe
     laba2\laba2.exe
     ```

### Что будет выведено / Инструкция пользователя
При запуске программа автоматически проводит демонстрацию сортировки пузырьком на трёх тест-кейсах.
Для каждого случая выводится состояние таблицы до и после сортировки, а также время работы.
После этого программа переходит в интерактивный режим **двоичного поиска** по ключу. Для выхода введите `-1`.

**Пример вывода:**

## 3 Лабораторная работа по АиСД

**Вариант:** 11 (Дерево арифметического выражения, вынесение общего множителя за скобки)

### Исходный код
* Файл с кодом: [laba3.c](laba3/laba3.c)

### Принцип работы и алгоритмы
1. **Представление узла (`Node`)**: Содержит тип (`type`: `'n'` для операнда, `'o'` для оператора), текстовое значение (`val`), символ операции (`op`) и левого/правого потомка (`left`/`right`).
2. **Анализ выражения (Парсер)**: Реализован алгоритм рекурсивного спуска. Грамматика выражения:
   * `expr -> mul ('+' mul)*`
   * `mul -> atom ('*' atom)*`
   * `atom -> число/переменная | '(' expr ')'`
3. **Вынесение общего множителя за скобки (`full_factor`)**:
   * Рекурсивно обходит дерево в поисках оператора сложения `+`.
   * Извлекает левый и правый операнды, ожидая, что они являются умножениями `*` (например, `l1 * l2` и `r1 * r2`), либо одиночными термами (рассматривается как `X * 1`).
   * Проверяет поддеревья на идентичность с помощью функции `same`.
   * При обнаружении общего сомножителя (например, `l1` совпадает с `r1`) перестраивает дерево: узел сложения заменяется на умножение общего множителя на сумму оставшихся сомножителей: `l1 * (l2 + r2)`.
   * Процесс повторяется итеративно, пока происходят изменения (`changed == 1`).

### Как запускать
1. Откройте терминал в корневой папке репозитория.
2. Скомпилируйте и запустите программу:
   * **macOS / Linux:**
     ```bash
     gcc laba3/laba3.c -o laba3/laba3
     ./laba3/laba3
     ```
   * **Windows (CMD / PowerShell):**
     ```cmd
     gcc laba3\laba3.c -o laba3\laba3.exe
     laba3\laba3.exe
     ```

### Что будет выведено / Инструкция пользователя
Программа считывает математическое выражение (поддерживаются сложение `+`, умножение `*`, переменные и скобки).
Она строит дерево выражения, выводит исходный вид и древовидное представление (обходом в глубину с отступами), затем пытается вынести общий множитель за скобки и выводит преобразованный результат с обновленным деревом.

**Пример ввода:**
```text
a*b+a*c
```

**Пример вывода:**
```text

a*b+a*c

Исходное выражение:
((a * b) + (a * c))

Исходное дерево:
+
   *
      a
      b
   *
      a
      c

После преобразования:
(a * (b + c))

Дерево после преобразования:
*
   a
   +
      b
      c
```

## 4 Лабораторная работа по АиСД

**Вариант:** 11 (Красно-черное дерево)

### Исходный код
* Файл с кодом: [laba4.c](laba4/laba4.c)
* Файл входных команд: [input.txt](laba4/input.txt)
* Файл результатов: [output.txt](laba4/output.txt)

### Принцип работы и алгоритмы
1. **Красно-черное дерево (RBT)**: Самобалансирующееся бинарное дерево поиска. Узлы содержат цвет (`color`: `RED` или `BLACK`), текстовый ключ длиной 1..6 символов и вещественное значение (`double value`). Имеется выделенный страж `nil` (черного цвета), заменяющий пустые указатели.
2. **Балансировка**:
   * **При вставке (`fix_insert`)**: Если нарушается свойство (красный узел имеет красного родителя), производятся перекраски и левые/правые повороты (`left_rotate`, `right_rotate`) в зависимости от цвета «дяди» узла.
   * **При удалении (`fix_delete`)**: Если удаляется черный узел (что нарушает баланс черной высоты), дерево балансируется путем перекрасок и вращений на основе цвета «брата» и его детей.
3. **Обработка команд**: Программа читает текстовые команды построчно из входного файла:
   * Команда `1`: вставка узла.
   * Команда `2`: удаление узла по ключу.
   * Команда `3`: вывод структуры дерева (обходом справа налево, чтобы дерево вывелось "на боку").
   * Команда `4`: поиск значения по ключу.

### Как запускать
Для правильной работы программы входной файл `input.txt` должен лежать в той же папке, откуда запускается исполняемый файл.

   ```bash
   cd laba4
   ```
2. Скомпилируйте и запустите программу:
   * **macOS / Linux:**
     ```bash
     gcc laba4.c -o laba4
     ./laba4
     ```
   * **Windows (CMD / PowerShell):**
     ```cmd
     gcc laba4.c -o laba4.exe
     laba4.exe
     ```

### Что будет выведено / Инструкция пользователя
Программа работает автономно, считывая команды из [input.txt](laba4/input.txt) и записывая результат в [output.txt](laba4/output.txt).

## 5 Лабораторная работа по АиСД

**Вариант:** 11 (Список рёбер, топологическая сортировка по алгоритму Кана)

### Исходный код
* Файл с кодом: [laba5.c](laba5/laba5.c)
* Тестовые примеры: [tests.md](laba5/tests.md)

### Принцип работы и алгоритмы
1. **Представление графа**: Список рёбер (`Edge` содержит поля `from` и `to`). Список вершин собирается динамически при вводе рёбер.
2. **Алгоритм Кана (Kahn's Algorithm)**:
   * Вычисляется полустепень захода (`in_degree`) для каждой вершины — количество входящих в нее рёбер.
   * Все вершины с `in_degree == 0` (в которые не входит ни одно ребро) помещаются в очередь `queue`.
   * Пока очередь не пуста:
     * Извлекается вершина из очереди и добавляется в массив результатов `result`.
     * Для всех рёбер, исходящих из этой вершины, уменьшается полустепень захода целевой вершины на 1.
     * Если полустепень захода какой-либо смежной вершины становится равной 0, она добавляется в очередь.
   * **Проверка цикла**: Если количество вершин в массиве результатов `result` меньше общего числа уникальных вершин графа, это означает, что в графе остался цикл (вершины с ненулевой полустепенью захода, которые невозможно отсортировать). В таком случае программа сообщает об ошибке. В противном случае выводится корректный топологический порядок.

### Как запускать
1. Откройте терминал в корневой папке репозитория.
2. Скомпилируйте и запустите программу:
   * **macOS / Linux:**
     ```bash
     gcc laba5/laba5.c -o laba5/laba5
     ./laba5/laba5
     ```
   * **Windows (CMD / PowerShell):**
     ```cmd
     gcc laba5\laba5.c -o laba5\laba5.exe
     laba5\laba5.exe
     ```

### Что будет выведено / Инструкция пользователя
Программа запрашивает количество рёбер в ориентированном графе, затем считывает сами рёбра в формате `откуда куда` (номера вершин — целые числа).
После этого она пытается выполнить топологическую сортировку алгоритмом Кана. Если в графе есть циклы, выводится соответствующее предупреждение.

**Пример ввода:**
